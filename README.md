# Java Data Structures and Algorithms (DSA)

This repository serves as a comprehensive log of my journey mastering Data Structures and Algorithms using Java. It acts as my central hub for sharpening problem-solving skills in preparation for university computer science studies and future technical interviews.

## 🧠 What's Inside?
The repository is organized by topic, moving from foundational Java concepts to advanced algorithmic problem-solving. 

Current topics include:
* **Basic Understanding & Variables:** Core Java syntax, data types, and inputs.
* **Control Flow:** Loops (`for`, `while`, `do-while`) and conditionals (`if/else`, `switch`).
* **Arrays & Strings:** 1D and 2D arrays, string manipulation, and the two-pointer approach.
* **Searching Algorithms:** Linear Search and Binary Search (including Order-Agnostic and 2D matrix searches).
* **Math Functions:** Exploring the `java.lang.Math` library and custom mathematical algorithms.

## 🛠️ Tech Stack
* **Language:** Java (JDK 17+)
* **IDE:** IntelliJ IDEA
* **Concepts:** OOP, Time/Space Complexity, Recursion (Upcoming)

## 🚀 How to Navigate
Each folder represents a specific topic or algorithm pattern. Inside, you will find heavily commented `.java` files containing:
1. The problem statement or concept.
2. The algorithmic approach.
3. The coded solution with edge cases handled.
